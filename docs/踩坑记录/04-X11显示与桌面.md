# 04 - X11 显示与桌面

## X server 的正确启动方式（不是发广播）
- 广播 `ACTION_START` 无效；必须 app_process 直跑 CmdEntryPoint，且环境变量一个都不能少：
  ```sh
  CLASSPATH=$APK TMPDIR=$R/tmp XKB_CONFIG_ROOT=$R/usr/share/X11/xkb \
  nohup /system/bin/app_process64 / --nice-name=termux-x11 com.termux.x11.CmdEntryPoint :0 &
  ```
- X socket 落在 `$R/tmp/.X11-unix/X0`（先 mkdir 777）；proot 模式把 Termux 的 `usr/tmp/.X11-unix` bind 成 `/tmp/.X11-unix`。
- 非 root 也可以这样跑 X server（termux-x11 官方玩法，本来就不需要 root）。

## 坑 1：X server 杀不掉
- **真因**：`/proc/<pid>/comm` 是 `main`（--nice-name 只改 cmdline），所有 `pkill -x termux-x11` 都是空操作。
- **解法**：`pgrep -f '[t]ermux-x11'`（方括号防自匹配）；循环 kill 确认退出后再删 socket，否则出现"X server 未启动"却连不上的死局。

## 坑 2：X 残留锁
- `$R/tmp/.X0-lock`、`.X11-unix/X0` 残留会让 X 直接退出。启动前清理，改成轮询等 socket 而非 sleep。

## 坑 3：chroot 起 XFCE 的环境变量
- **现象**：桌面内终端打不开/黑屏。
- **真因**：session 继承了 Android 的 `SHELL=/system/bin/sh`（chroot 里不存在）和 `TERM=dumb` → xfce4-terminal 执行 shell 失败。
- **解法**：启动时 `export SHELL=/bin/bash TERM=xterm-256color`；`exo-open --launch TerminalEmulator` 路径环境传递有问题，把对应 .desktop 的 Exec 改成直接 `xfce4-terminal`。

## 坑 4：XFCE 必须"先有 Surface 再启动"
- **现象**：App 后台时启动桌面，所有窗口初始化成 10x10，切回前台也不重画 → 永远黑屏。
- **解法**：先 `am start` X11 Activity 等它前台（Surface 有效），再拉桌面组件。

## 坑 5：桌面"点不了"的三类真凶（都不是 XFCE 崩）
1. `xfce4-mime-helper` 找不到合法浏览器 helper → 模态框抢焦点。修法：写 `/usr/share/xfce4/helpers/xxx.desktop`（Type=X-XFCE-Helper）+ `~/.config/xfce4/helpers.rc` + xdg-utils。
2. **鬼影像素**：已关闭窗口不重绘，残留"假弹窗"；xwininfo 树里查不到 = 鬼影，`xrefresh` 或 `xfdesktop --reload` 消除。
3. Android 软键盘被唤出抢触摸 → `input keyevent 111`(ESC) 收起。

## 坑 6：分辨率/缩放
- 设备 2880x1800，X 默认 96dpi 按物理分辨率渲染，元素只有 Android 应用的 ~47%。
- termux-x11 内建 `displayResolutionMode=scaled + displayScale=200`，改 prefs **无需重启桌面**（RRScreenSizeSet 动态生效）。
- **v22 教训**：全局缩放会把桌面里的 Chrome 页面一起放大 → 不要自动缩放，保留手动按钮（100~200% 五档）。想只放大字体应走 XFCE 的 Xft/DPI 设置。

## 坑 7：SurfaceView 渲染停止 / screencap 黑图
- 反复 force-stop + 屏幕 doze 后 SurfaceView 0x0 0.4FPS，杀进程/旋转均无效 → 只能 adb reboot。
- **screencap 恒定黑图 ≠ 桌面没跑**（xlsclients 里 xfdesktop 全活着）；另：重启后 CE 存储未解锁时 /data/data 目录名会显示乱码。

## 坑 8：Termux:X11 附加键条
- 关闭：prefs `showAdditionalKbd=false`（**必须 force-stop 之后再改**，应用退出会回写 prefs）。
- `pkill -f termux-x11` 会把自己的 adb shell 一起杀，用 `pidof`。
- `backButtonAction="toggle soft keyboard"` 时按返回键是"切换"软键盘，容易误触发。

## 调试利器
- `xwininfo -root -tree`：查窗口映射状态（10x10 = 未映射）；`xlsclients`：确认客户端活着；`xrefresh`：清鬼影。
