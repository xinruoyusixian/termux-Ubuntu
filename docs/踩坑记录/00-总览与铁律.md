## 最高优先级铁律（违反过，代价惨重）

1. **任何对 rootfs 目录（files/ubuntu）的 `-R` 批量操作（chcon/chown/chmod/rm/tar）之前，必须先卸载它的全部 bind mount。** bind mount 会穿透：`chcon -R files/ubuntu` 曾把真实 `/dev/null` 的 SELinux 标签改成 app_data_file，导致全系统 zygote 无限崩溃；`rm -rf` 曾穿透删掉 /sdcard 内容并卸掉 /dev/pts。
2. **永远不要用 `pkill -f` 杀"名字会出现在自己命令行里"的进程**（su -c / 脚本路径字面量都会自匹配）。按 pid 文件或 `pgrep -x 进程名` 杀。
3. **root 会话创建的任何文件/目录都可能变成 root 属主**，切非 root 后 App uid 写不了 → 启动脚本静默失败。共享目录（log 等）root 侧建完要 `chmod 777` 或 chown 10183。
4. **测试不要用真实 root 跑 proot/chroot 桌面程序**：会往 /home/alan 写 root 属主文件，引发"系统无法读取偏好设置"这类事后难查的问题。
