# 源码改动说明（相对上游 termux-app v0.118.3）

最终版：**v28**（v27 修复 + 菜单上下文化）。所有改动都在 `termux-app-master/` 内，系统包（rootfs）已外置为 `/sdcard/UbuntuXFCE/rootfs.tar.gz`（本地备份见 `资源包/系统包/`）。

## 一、新增 Java 类

### `app/src/main/java/com/termux/app/LinuxLauncher.java`（全新，核心）
- **root 检测** `hasRoot()`：优先 PackageManager 检测 KernelSU 管理器包名（`me.weishu.kernelsu`），支持 `files/.force-noroot` 标记强制走非 root（调试逃生口）
- **系统准备** `prepare()`：首次从 `/sdcard/UbuntuXFCE/rootfs.tar.gz` 等外置路径导入系统包（无外置包时报错提示），root 用 `tar xzpf` 保权限解压 + `fix_perms.sh` 校正属主；就绪判断探测 `usr/bin/bash` 而非依赖标记文件
- **启动计划**：root → `su -c` 挂 proc/sys/dev/dev/pts + 清残留看门狗（按 pid 文件）+ 后台拉 `start-xfce.sh` + 看门狗；非 root → 复制脚本后跑 `start-xfce-noroot.sh`。启动前 `mkdir -p files/log && chmod 777`（防 root 会话留下的 root 属主 log 目录卡死非 root 启动）
- **生命周期**：`killSession` / `resetRootfs`（rm 前强制护栏：仍有挂载即 ABORT，绝不 rm -rf）/ `reimportRootfs`，均按 hasRoot 分流
- **存储**：`hasStorageAccess/openStorageSettings/mountStorage`（菜单「挂载 SD」）；非 root 直接返回"已随桌面自动挂载"
- **界面缩放**：`getDisplayScale/setDisplayScale/nextDisplayScale`（100~200% 五档，写 termux-x11 prefs，即时生效）

### `app/src/main/java/com/termux/app/PadMenu.java`（全新，菜单动作层）
- `openDesktop`（终端→桌面）、`openTermux`（桌面→终端，REORDER_TO_FRONT 复用实例）
- `startDesktopStack` / `restartDesktop` / `restartAudio` / `stopDesktop` / `mountSd` / `importRootfs`
- 所有动作按 `hasRoot()` 分流 `runSu` / `runSh`；Toast 统一置顶显示（防被桌面面板挡住）

## 二、改动的 Java

- `TermuxActivity.java`：启动回调改异步 `prepare()` 后带命令开新会话；抽屉菜单从右侧滑出（Gravity.RIGHT）+ Ubuntu 橙标题条；桌面控制按钮组（进入桌面/重启/音频/导入/关闭系统[带确认]/随App关闭/挂载SD[非root隐藏]/界面缩放）
- `TermuxTerminalSessionActivityClient.java`：新增 `addNewSessionWithCommand(executable, args, name)`
- `TermuxApplication.java`：申请媒体焦点的入口协作（v20 音频 Anti-AudioHardening）
- `x11/MainActivity.java`：悬浮菜单面板（可拖动 ≡ 按钮）——终端模式（第一导航项）/重启桌面/重启音频/挂载SD（非root隐藏）/导入系统包/界面缩放/关闭系统（最底部）/随App关闭开关；前台时持有媒体焦点（AUDIOFOCUS_GAIN, USAGE_MEDIA）解决车机 AudioHardening 静音
- `x11/` 内其余为合并进来的 termux-x11 源码（X server 以 app_process 直跑）

## 三、assets（随 APK 分发，改脚本不用重打系统包）

| 文件 | 用途 |
|---|---|
| `start-xfce.sh` | root 版一条龙：补挂载→X server(app_process)→Activity→音频→chroot 起 XFCE |
| `start-desktop.sh` | chroot 内起 XFCE（alan 用户 + 固定地址 dbus + session.env + fcitx5 兜底） |
| `start-xfce-noroot.sh` | 非 root 版：X/音频直接以 App uid 跑，proot -0 伪装 root 拉桌面；proot bind `chrome-noroot.sh` 覆盖 `/usr/bin/google-chrome-stable`；`unset LD_PRELOAD`；`HOME=/root` |
| `start-desktop-noroot.sh` | proot 内手动直启 XFCE 组件（不用 startxfce4，避开黑屏）+ 关合成器 + fcitx5 兜底 |
| `chrome-noroot.sh` | Chrome 兼容 shim（--no-sandbox 等），仅非 root 会话经 proot bind 生效 |
| `linux-cleanup.sh` / `linux-cleanup-noroot.sh` | 杀进程 + 卸载全部挂载（rm 前护栏） |
| `linux-watchdog.sh` | 「随 App 关闭」看门狗（按 pid 文件管理） |
| `mount-sd.sh` | nsenter 进 init mount ns → media_rw 组 → pass_through 直通 bind 进 chroot |
| `fix_perms.sh` | 解压后统一校正属主/权限（chown 10183、suid） |
| `start-audio.sh` / `pa-user.pa` | PulseAudio（module-aaudio-sink，setsid 前台常驻） |
| `termux-pkgs.bin` | Termux 侧 pulseaudio/proot/libtalloc 随包分发（打包时强制 755） |

## 四、构建配置（app/build.gradle 等）

- `androidResources.noCompress += ["tar.gz","bin"]`（大 asset 不 deflate，可取 fd）
- `downloadBootstraps` 只留 aarch64；三模块 `abiFilters` 只留 arm64-v8a
- release 用 debug key 签名（`testkey_untrusted.jks`）可直接 sideload
- 构建要求：Gradle 9.2.1 + AGP 8.13.2 + NDK 29.0.14206865 + JDK17 + SDK36
- 构建命令：`JAVA_HOME=D:\carapp-dev\jdk`（需 JDK 含 javac）+ `gradlew :app:assembleRelease -PappVersionName=0.118.0-vXX`
- gradle 9.2.1 发行版 zip 需在 `~/.gradle/wrapper/dists/gradle-9.2.1-bin/2t0n5ozlw9xmuyvbp7dnzaxug/`（网络不通时手动放）
