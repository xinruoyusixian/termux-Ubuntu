# Ubuntu XFCE 平板版 —— 使用与部署说明

一台小米 Pad 6 Pro（LineageOS / Android 16 / KernelSU）上"安装即用"的 Ubuntu 24.04 XFCE 桌面方案。root（chroot）与非 root（proot）双模式，Chrome 浏览器、fcitx5 中文输入法、音频、SD 卡共享、SSH 全部内置可用。

## 一、安装

1. 安装 `Ubuntu-XFCE-Tablet-v28.apk`（49MB）——**显示端（Termux:X11 / Lorie）已内置在同一安装包里，无需另装**
2. 首次启动需系统包（二选一）：
   - 外置包（推荐，~861MB）：把 `Ubuntu-XFCE-rootfs.tar.gz` 放到平板 `/sdcard/UbuntuXFCE/rootfs.tar.gz`，再打开 App
   - 无外置包时会提示找不到系统包
3. root 设备：在 KernelSU 管理器里给 com.termux 授权（没授权 su 不可见，会自动走非 root）
4. 建议给 Termux / Termux:API 关闭电池优化，防止 pulseaudio 被杀

> 注：`Termux-X11.apk`（独立显示端，包名 com.termux.x11）**只有配合原版 Termux 才需要**，本 App 用不到。

## 二、两种模式

| | root（chroot） | 非 root（proot） |
|---|---|---|
| 判定 | 有可用 su 且无 `.force-noroot` 标记 | 无 su，或存在 `/data/data/com.termux/files/.force-noroot` |
| 原理 | 真实 chroot + 18 个挂载点，桌面以用户 alan(uid=10183) 运行 | proot -0 伪装 root，全部进程以 App uid(10183) 运行 |
| 常驻 | 支持（「随 App 关闭」开关控制看门狗） | 天然随 App 退出（force-stop 即全停） |
| 切换 | 建 `.force-noroot` → 非 root；删除该文件 → root。切换后重启 App 生效 | 同左 |

## 三、菜单（上下文相关）

- **终端模式**（Termux 界面，右侧抽屉，橙色标题条）：
  「进入桌面」= 切到 X11 桌面（并幂等拉起桌面栈）；重启 / 音频 / 导入 / 关闭系统（有确认）/ 随App关闭 / 挂载SD（仅 root 显示）/ 界面缩放
- **桌面模式**（X11 界面右上角可拖动 ≡）：
  「终端模式」= 回终端；重启桌面 / 重启音频 / 挂载SD / 导入系统包 / 界面缩放 / 关闭系统

## 四、桌面内常用入口

- 浏览器：应用菜单 / 桌面图标 Chrome（`/usr/local/bin/chrome`，含输入法/音频/缩放环境）；命令行 `browse [网址]`
- 输入法：fcitx5 + WowType，Ctrl+Space 中英切换；命令行 `im` / `im cn` / `im en` / `im st`；桌面有「中英切换」图标
- SSH：端口 2222，用户 alan/alan（或 root/root），`ssh alan@<平板IP> -p 2222`
- SD 卡：桌面「SD卡」图标 / `~/SD卡` → `/mnt/sdcard`（root 模式需先在菜单挂载或授权）
- 急救：`/root/fix-desktop.sh`（root）/ 菜单「重启桌面」

## 五、重新构建 APK

见 `源码/源码改动说明.md` 第四节。改 assets 里的脚本只需重编 APK（几十秒），不用动 902MB 系统包。

## 六、常见问题

- **点浏览器没反应**：v27 已修（proot 伪装 root 触发 Chrome 沙箱拒绝）；确认 ≥ v27
- **没声音**：先「重启音频」；看 `dumpsys audio` 是否有 `OpPlayAudio muted`（v20 已修，媒体焦点方案）
- **打字只有英文**：会话总线断了，跑 `/usr/local/bin/ub-ime` 或重启桌面
- **切换模式后桌面起不来**：v27 已修 log 目录属主问题；仍不行看 `files/log/desktop-start.log`
- **重新导入系统**：菜单「导入系统包」，需先把 tar.gz 放回 /sdcard/UbuntuXFCE/
