# Ubuntu XFCE 平板版 —— 使用与部署说明

安卓平板（示例：小米 Pad 6 Pro / LineageOS / Android 16 / KernelSU）上"安装即用"的 Ubuntu 24.04 XFCE 桌面方案。root（chroot）与非 root（proot）双模式，Chrome、fcitx5 中文输入法、音频、下载目录共享、SSH 全部内置可用。当前版本 **v36**。

## 一、安装

1. 安装 `Ubuntu-XFCE-平板版-v36.apk`（48MB）——**显示端（Lorie/X11）已内置在同一安装包里，无需另装 Termux:X11**
2. 首次启动需系统包：把 `Ubuntu-XFCE-rootfs-v36.tar.gz`（815MB）放到平板 `/sdcard/UbuntuXFCE/rootfs.tar.gz`，再打开 App，会自动导入
   - 该发布包**不含任何个人信息**（打包前已清理 Chrome profile/历史/缓存）
3. 默认进入**非 root（proot）模式**，无需 root 即可用
4. 若要用 root 模式：在 KernelSU/Magisk 里给 com.termux 授权，然后在终端菜单切换（见第三节）
5. 建议关闭 Termux 的电池优化，防止 pulseaudio 被后台杀掉

> 注：`Termux-X11.apk`（独立显示端）**只有配合原版 Termux 才需要**，本 App 用不到。

## 二、两种模式

| | root（chroot） | 非 root（proot） |
|---|---|---|
| 判定 | 实测 `su -c id` 返回 uid=0 且无 `.force-noroot` 标记 | 无可用 su，或存在 `/data/data/com.termux/files/.force-noroot` |
| 原理 | 真实 chroot + 挂载点，桌面以用户 alan 运行（uid 动态取当前 App uid） | proot -0 伪装 root，全部进程以 App uid 运行 |
| 默认 | 否（首次启动默认非 root） | **是** |
| 常驻 | 支持（「随 App 关闭」开关控制看门狗） | 天然随 App 退出 |
| 切换 | 终端抽屉「模式：非root」按钮 → 确认 → 可选立即重启系统 | 同左 |

**root 检测说明**：装了 KernelSU/Magisk 管理器 ≠ su 可用。App 会实测 `su -c id`，多 su 路径逐个尝试；su 丢失/未授权时自动降级非 root，不会再报 `No su program found on this device...`。切换模式时若设备真没 root，会提示「此设备没有可用的 root，无法切换到 root 模式」。检测在子线程执行，授权弹窗不会卡死界面。

**uid 自适应**：不同设备的 `com.termux` uid 可能不同（10183、10167…），格式化重装后也会变。所有脚本运行时用 `stat -c %u` 动态取当前 uid，并同步改 rootfs 的 `/etc/passwd`、`/etc/group` 属主，不会因 uid 写死而黑屏。

## 三、菜单（上下文相关，已全部汉化）

- **终端模式**（Termux 界面，右侧抽屉，橙色标题条）：
  - 进入桌面（切到 X11 桌面，幂等，全局只保留一个 X11 窗口）
  - 重启系统（彻底关闭 X/桌面/音频后重拉整套）、重启音频、导入系统包
  - 关闭系统（有确认，同时杀掉 App 回到安卓桌面）、随 App 关闭（开关）
  - 挂载下载（root/非 root 都可用）、**模式：非root/root**（切换，无 root 会提示）
  - **备份系统 / 恢复备份**、界面缩放
- **桌面模式**（X11 界面右上角可拖动 ≡）：
  - 终端模式（回终端）、重启系统、重启音频、挂载下载、导入系统包
  - **备份系统 / 恢复备份**、界面缩放、关闭系统

Termux 原生的长按终端菜单（选择链接/分享/重置/结束进程/样式/设置等）和设置页也已全部中文。

## 四、下载目录（双模式）

菜单「挂载下载」在 root 和非 root 下都可见可用：

1. 首次点击若没有「所有文件访问」权限，会弹说明并跳到系统设置
2. 开启「允许访问所有文件」后返回，会自动完成挂载
3. 桌面里的下载目录位于 `/mnt/download`，对应安卓的 `/sdcard/Download`，可读写用于数据交换
4. 采用 App 私有暂存区 + 同步脚本，**卸载 App / 清数据不会穿透删除 SD 卡里的文件**

## 五、备份与恢复

**备份**（含你的个人信息）：
- 终端或桌面菜单点「备份系统」→ 确认 → 等待几分钟
- 备份包生成在 `/sdcard/UbuntuXFCE/backups/ubuntu-backup-<时间戳>.tar.gz`，包含当前系统全部数据（浏览器记录、登录、文档、输入法词库等）
- 备份会先关闭正在运行的桌面程序；包放在公共存储，**请妥善保管**

**恢复**：
- 把备份包放在 `/sdcard/UbuntuXFCE/backups/`（或 `/sdcard/Download/`）
- 菜单点「恢复备份」→ 选择备份包 → 确认
- 会关闭桌面并清空当前系统后用备份覆盖，**当前系统未备份的改动会丢失**
- 恢复时用 root 还原属主/setuid，并按当前设备 uid 自适应校正

## 六、桌面内常用入口

- 浏览器：桌面图标 Chrome（`/usr/local/bin/chrome`）；命令行 `browse [网址]`
- 输入法：fcitx5 + WowType，Ctrl+Space 中英切换；命令行 `im` / `im cn` / `im en` / `im st`
- SSH：端口 2222，用户 alan/alan（或 root/root），`ssh alan@<平板IP> -p 2222`
- 下载目录：桌面 `/mnt/download`（见第四节）
- 急救：`/root/fix-desktop.sh`（root）/ 菜单「重启系统」

## 七、重新构建

见 `docs/源码改动说明.md`。要点：

```bash
# APK：改 assets 脚本或 Java/布局后重编（几十秒）
export JAVA_HOME=<jdk路径>
cd termux-app-master && ./gradlew :app:assembleRelease -PappVersionName=0.118.0-v36

# rootfs：在安卓设备上打包（避免权限问题），推送 tools/pack_v36_on_device.sh 执行
# 发布前务必先跑 tools/clean_rootfs.sh 清除个人信息
```

## 八、常见问题

- **点浏览器没反应**：≥ v27 已修 Chrome 沙箱；核心是 `TMPDIR` 不能指向安卓 cache，脚本已固定 `TMPDIR=/tmp`
- **没声音**：先「重启音频」；看 `dumpsys audio` 是否 `OpPlayAudio muted`
- **打字只有英文**：跑 `/usr/local/bin/ub-ime` 或重启桌面
- **root 模式黑屏只有光标**：uid 错配（v34 已修）。看 `files/log/xfce.log` 是否 `cannot change directory to /home/alan: Permission denied`；v36 会动态改 passwd/group 属主
- **root 下 Termux 报错 RunCommandService requires allow-external-apps**：v33 已自动开启该开关
- **装了 KernelSU 但切不了 root**：su 未实际授权；在管理器里给 com.termux 授权 su 后再切
- **切换模式后桌面起不来**：看 `files/log/desktop-start.log`；菜单「重启系统」重试
- **重新导入系统**：菜单「导入系统包」，需先把 tar.gz 放回 `/sdcard/UbuntuXFCE/`
- **备份包很大**：整系统约 800MB，属正常；用 `gzip -1` 已平衡速度与体积
